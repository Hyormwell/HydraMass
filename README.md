## CLI Usage

Команда `hydra-reposter send` поддерживает следующие опции:

| Флаг                   | Сокращение | Описание                                                                      | Пример                              |
|------------------------|------------|-------------------------------------------------------------------------------|-------------------------------------|
| `--csv`, `-c`          | —          | Путь к CSV-файлу с колонкой `username` для таргетов                           | `--csv targets.csv`                 |
| `--donor`, `-d`        | —          | Ссылка или username канала‑донора, из которого пересылаются сообщения          | `--donor t.me/MyChannel`            |
| `--msg-ids`, `-m`      | —          | Список ID сообщений в канале‑доноре для пересылки                              | `--msg-ids 1 2 3`                   |
| `--sessions-dir`, `-s` | —          | Каталог с файлами `.session` для авторизации аккаунтов                        | `--sessions-dir sessions`           |
| `--rate`               | —          | Скорость работы: `slow` (1 сообщение за раз) или `fast` (3 сообщения за раз)   | `--rate fast`                       |

### Пример запуска

```bash
hydra-reposter send \
  --csv data/targets.csv \
  --donor t.me/MyChannel \
  --msg-ids 1 2 3 \
  --sessions-dir sessions \
  --rate fast
